# Asset placeholders

Drop your files into `/public/assets/` with these names:

- `hero-loop.mp4` — Looping 3D hero animation (Möbius/torus). Used as fallback under WebGL.
- `profile.webp` — Profile photo (square, ~600×600).
- `loader.gif` — Intro loading screen animation.
- `resume.pdf` — Downloadable resume.
